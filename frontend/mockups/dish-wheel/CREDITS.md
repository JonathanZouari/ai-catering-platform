# Dish-wheel preview — credits

Interaction pattern inspired by a pizza-ordering concept short: https://youtube.com/shorts/8aVtfvaapuA (no assets or copy reused).

## Font

Rubik (Hebrew + Latin), SIL Open Font License 1.1. Files in `fonts/`, full license in `fonts/OFL.txt`. Self-hosted so this preview does not call Google Fonts.

## Sample prices

Figures in `js/mock/catalog.js`, including chicken per kilogram, are sample data for the design review. The on-screen total is computed in the browser for this preview only. The real build renders server pricing (ADR 0003) and must not treat these numbers as prices.
