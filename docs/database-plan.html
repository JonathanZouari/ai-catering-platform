3. הטבלאות

משתמשים

customers

לקוחות. נוצרים בתשלום מפרטי הקשר; אין חובה להירשם.

  • id uuid PK
  • auth_user_id null, unique → auth.users
  • full_name not null
  • email, phone
  • created_at, updated_at

מנות ומחירים

dish_categories

9 קטגוריות: ראשונות, עיקריות, תוספות, סלטים, קינוחים, משקאות, יינות, כלים, אביזרים.

  • id uuid PK
  • name unique
  • sort_order, is_active

dishes

כל פריט שנמכר, כולל מחיר.

  • id uuid PK
  • category_id FK
  • kind food | drink | tools
  • name, description, image_path
  • pricing_unit per_guest | per_tray | per_weight | per_item
  • unit_price numeric(10,2) ≥ 0
  • unit_label, min_quantity
  • currency ILS
  • is_available

dish_dietary

צמחוני/טבעוני. null = לא ידוע (לא "לא").

  • dish_id PK/FK
  • is_vegetarian, is_vegan bool null
  • verified_at

allergens / dish_allergens

אלרגנים לכל מנה. שורה חסרה = לא ידוע.

  • allergens: id, name unique
  • dish_allergens: dish_id, allergen_id, status contains | free | unknown

ארוחות שלמות

meal_packages

4 חבילות במחיר לסועד: ים-תיכוני 95, איטלקי 110, מקסיקני 100, תאילנדי 105.

  • id uuid PK
  • code unique: med/ita/mex/tha
  • name, cuisine, description
  • price_per_guest numeric(10,2)
  • currency, is_active

meal_package_drinks

3 משקאות מוצעים לכל חבילה.

  • package_id FK
  • dish_id FK
  • PK (package_id, dish_id)

אירועים ולוגיסטיקה

events

האירוע שהלקוח מתכנן.

  • id uuid PK
  • customer_id FK
  • event_type FK → event_types
  • event_date, time_slot_id FK
  • adults, children
  • omnivore_guests, vegetarian_guests, vegan_guests, restricted_guests
  • dietary_notes, notes
  • CHECK adults + children > 0

event_types

12 סוגי אירוע (בר מצווה, שבת, יום הולדת…).

  • code PK
  • label, sort_order

time_slots

3 חלונות: 11–13, 17–19, 19–21.

  • id, fulfillment_type null = שניהם
  • weekday, start_time, end_time
  • capacity, is_active

blocked_dates

תאריכים סגורים.

  • id, date unique, reason

delivery_zones

אזורי משלוח; ברירת מחדל ₪120.

  • id, name, fee ≥ 0
  • definition jsonb, is_active

הזמנות

orders

הזמנה אחת לכל אירוע.

  • id, customer_id, event_id unique
  • status draft → pending_approval → approved | rejected
  • version נעילה אופטימית
  • fulfillment_type pickup | delivery
  • requested_at, delivery_address, delivery_zone_id
  • subtotal, delivery_fee, total
  • submitted_at, decided_at, decision_note
  • CHECK משלוח ⇒ כתובת חובה

order_items

שורות הזמנה: מנה או חבילה.

  • id, order_id FK
  • dish_id null, package_id null
  • CHECK בדיוק אחד מהם
  • quantity > 0
  • snapshot_name / pricing_unit / unit_price / line_total מחיר קפוא בשליחה

העוזר החכם

ai_conversations

שיחה לכל הזמנה.

  • id, order_id, created_at

ai_messages

הודעות.

  • id, conversation_id
  • role user | assistant | tool
  • content jsonb

ai_change_proposals

הצעות שינוי שהבעלים/לקוח מאשרים.

  • id, order_id, conversation_id
  • base_order_version
  • changes jsonb
  • price_before, price_after
  • status pending | approved | rejected | expired | failed
  • executed_at אידמפוטנטיות
  • הצעה pending אחת לכל הזמנה

4. הרשאות (RLS)

מימה
כל אחד (anon)קריאה בלבד: קטלוג (קטגוריות, מנות, חבילות, אלרגנים), סוגי אירוע, חלונות זמן, אזורי משלוח
לקוח מחובררואה רק את השורות שלו: customers, events, orders, order_items
הבאקאנד (service role)כתיבה לכל הטבלאות. יצירת הזמנות ואירועים עוברת רק דרכו

7. פתוח / סיכונים
